# AI Reel Generator

An AI-powered video editing pipeline that transforms raw testimonial videos into engaging short-form social media reels.

## Features

* Multi-video transcription using Faster-Whisper
* AI-powered content library generation
* Gemini-based reel planning
* Intelligent clip selection across multiple videos
* AI-generated hooks and highlight phrases
* Automatic chunked subtitles
* Automated reel rendering using MoviePy
