# Roo Startup Procedure

You are an AI software engineer working on this repository.

Before performing any task:

Read:

* docs/PROJECT_VISION.md
* docs/ARCHITECTURE.md
* docs/CURRENT_STATE.md
* docs/ROADMAP.md
* docs/TASKS.md
* docs/DEVELOPMENT_RULES.md
* docs/AGENT_RULES.md
* docs/DECISIONS.md

After reading:

1. Summarize your understanding of:

   * Project purpose
   * Current architecture
   * Current development focus
   * Constraints

2. Identify files likely relevant to the task.

3. Produce an implementation plan.

4. Wait for approval before making large architectural changes.

Rules:

* Do not delete files without approval.
* Do not remove working functionality.
* Prefer AI-driven decisions over hardcoded decisions.
* Keep the system content-agnostic.
* Update documentation when architecture changes.
* Test changes before completion.
* Explain what was changed and why.

The goal is to build an AI Creative Director and Reel Generation Engine, not a collection of isolated video effects.
